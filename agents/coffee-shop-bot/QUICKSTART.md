# ⚡ Быстрый старт - Telegram бот для кофейни

## 🎯 3 шага до запуска бота

### ШАГ 1: Создайте бота в Telegram (2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду: `/newbot`
3. Придумайте имя: `Моя Кофейня`
4. Придумайте username: `my_coffee_shop_bot`
5. **Скопируйте токен** (выглядит так: `123456:ABC-DEF1234...`)

### ШАГ 2: Установите и запустите (1 минута)

```bash
# Перейдите в папку
cd agents/coffee-shop-bot

# Установите зависимости
pip install python-telegram-bot

# Запустите бота с вашим токеном
export TELEGRAM_BOT_TOKEN='ваш_токен_от_BotFather'
python coffee_bot.py
```

### ШАГ 3: Тестируйте! (30 секунд)

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Заказывайте напитки! ☕

## 🎨 Что умеет бот

### ☕ Меню

- **Классический кофе:** Эспрессо, Американо, Капучино, Латте и др.
- **Горячие напитки:** Глинтвейн, Пунши
- **Авторский кофе:** Рафы, авторские латте
- **Не кофе:** Чай, Какао, Матча

### 🛒 Корзина

- Добавление нескольких напитков
- Выбор объёма для каждого
- Добавление дополнений (сиропы, сливки и т.д.)
- Автоматический подсчёт стоимости

### ✅ Оформление

- Красивый чек заказа
- Информация о клиенте
- Полная стоимость
- Можно отправить администратору

## 🔧 Настройка

### Изменить меню

Отредактируйте `menu_data.py`:

```python
"Новый напиток": {
    "volumes": {"350мл": 250, "450мл": 300}
}
```

### Добавить администратора

1. Узнайте свой chat_id через [@userinfobot](https://t.me/userinfobot)
2. Добавьте в `.env`:
```
ADMIN_CHAT_ID=123456789
```
3. Раскомментируйте строку в `coffee_bot.py`:
```python
await context.bot.send_message(ADMIN_CHAT_ID, f"Новый заказ:\n{order_text}")
```

## 💡 Советы

### Для тестирования

- Используйте свой личный Telegram для первого запуска
- Проверьте все категории меню
- Попробуйте разные объёмы
- Протестируйте добавки

### Для продакшена

- Запустите бота на сервере (не на локальном компьютере)
- Добавьте администратора для получения заказов
- Настройте уведомления
- Подключите базу данных для сохранения истории

### Для безопасности

- Никогда не публикуйте токен бота
- Используйте `.env` файл для токена
- Не коммитьте `.env` в git
- Регулярно обновляйте зависимости

## 🆘 Проблемы?

### Бот не запускается

```bash
# Проверьте Python
python --version  # Должен быть 3.8+

# Проверьте зависимости
pip list | grep telegram

# Переустановите
pip install --upgrade python-telegram-bot
```

### Бот не отвечает

1. Проверьте токен
2. Проверьте интернет
3. Проверьте логи

### Кнопки не работают

Обновите библиотеку:
```bash
pip install --upgrade python-telegram-bot
```
