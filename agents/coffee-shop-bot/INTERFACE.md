## 🎬 Сценарий использования

### Сценарий 1: Простой заказ

```
Пользователь → /start
Бот          → Показывает главное меню

Пользователь → ☕ КЛАССИЧЕСКИЙ КОФЕ
Бот          → Показывает список кофе

Пользователь → Капучино - от 249₽
Бот          → Показывает объёмы

Пользователь → 350мл - 249₽
Бот          → Добавлено! Показывает добавки

Пользователь → ✅ Без добавок
Бот          → Что-нибудь ещё?

Пользователь → 🛒 Корзина
Бот          → Показывает корзину с заказом

Пользователь → ✅ Оформить заказ
Бот          → Заказ оформлен! ✅
```

### Сценарий 2: Заказ с добавками

```
Пользователь → /start
Бот          → Главное меню

Пользователь → ⭐ АВТОРСКИЙ КОФЕ
Бот          → Список авторского кофе

Пользователь → Раф халва - от 299₽
Бот          → Выберите объём

Пользователь → 450мл - 349₽
Бот          → Хотите добавить что-нибудь?

Пользователь → Сироп +51₽
Бот          → Добавлено! Ещё добавки?

Пользователь → Сливки +51₽
Бот          → Добавлено! Ещё добавки?

Пользователь → ✅ Готово
Бот          → Что-нибудь ещё?

Пользователь → 🛒 Корзина
Бот          → Раф халва 450мл с добавками = 451₽

Пользователь → ✅ Оформить заказ
Бот          → Заказ оформлен! ✅
```

### Сценарий 3: Несколько напитков

```
Пользователь → /start
Бот          → Главное меню

Пользователь → ☕ КЛАССИЧЕСКИЙ КОФЕ
Бот          → Список кофе

Пользователь → Американо - от 199₽
Бот          → Выберите объём

Пользователь → 350мл - 249₽
Бот          → Добавки?

Пользователь → ✅ Без добавок
Бот          → Что-нибудь ещё?

Пользователь → 🍵 НЕ КОФЕ
Бот          → Список не кофе

Пользователь → Чай - 99₽
Бот          → 350мл - 99₽

Пользователь → 350мл - 99₽
Бот          → Добавлено!

Пользователь → 🛒 Корзина
Бот          → 1. Американо 350мл - 249₽
             → 2. Чай 350мл - 99₽
             → Итого: 348₽

Пользователь → ✅ Оформить заказ
Бот          → Заказ оформлен! ✅
```

## 💡 Особенности интерфейса

### ✅ Удобство

- Большие кнопки (легко нажимать)
- Эмодзи для визуального разделения
- Цены сразу видны
- Минимум шагов до заказа

### 🎨 Дизайн

- Четкая структура
- Логичная навигация
- Всегда видна кнопка "Назад"
- Корзина доступна везде

### ⚡ Скорость

- Мгновенный отклик
- Никаких задержек
- Плавная навигация
- Быстрое оформление
