🚀 Быстрый старт

ШАГ 1: Создайте бота в Telegram (2 минуты)

  1. Откройте @BotFather в Telegram
  2. Отправьте команду: /newbot
  3. Придумайте имя: Моя Кофейня
  4. Придумайте username: my_coffee_shop_bot
  5. Скопируйте токен (будет выглядеть так: 123456:ABC-DEF...)

ШАГ 2: Установите зависимости (30 секунд)

cd agents/coffee-shop-bot pip install python-telegram-bot

ШАГ 3: Запустите бота (10 секунд)

export TELEGRAM_BOT_TOKEN='ваш_токен_от_BotFather' python coffee_bot.py

✅ Готово! Бот работает!
