# 📱 Как получить mobile_web.html на смартфон

## 🎯 САМЫЙ ПРОСТОЙ СПОСОБ - Прямая ссылка

После того как изменения будут в GitHub, файл будет доступен по адресу:

```
https://github.com/sentrymind/kubernetes-monitoring-stack/blob/claude/scientific-sources-agent-011CUd7vAk9s6juvMG5bBi3H/agents/scientific-history-agent/mobile_web.html
```

### Как использовать:

**Вариант 1: Открыть сразу в браузере**

1. На смартфоне откройте браузер (Chrome/Safari)
2. Перейдите по ссылке выше
3. Нажмите кнопку **"Raw"** (справа сверху)
4. Добавьте страницу в закладки
5. Готово! Теперь можно использовать

**Raw ссылка (для прямого открытия):**
```
https://raw.githubusercontent.com/sentrymind/kubernetes-monitoring-stack/claude/scientific-sources-agent-011CUd7vAk9s6juvMG5bBi3H/agents/scientific-history-agent/mobile_web.html
```

## 📲 Другие способы получить файл

### Способ 2: QR код

Я создам QR код, который можно отсканировать смартфоном.

### Способ 3: Email

Отправьте файл себе на почту:

```bash
# На компьютере
cd /home/user/kubernetes-monitoring-stack/agents/scientific-history-agent

# Если у вас настроена почта в системе
mail -s "Scientific History Agent" your-email@example.com < mobile_web.html
```

### Способ 4: Облако (Dropbox/Google Drive/iCloud)

```bash
# Скопируйте файл в вашу папку облака
cp /home/user/kubernetes-monitoring-stack/agents/scientific-history-agent/mobile_web.html ~/Dropbox/
# или
cp /home/user/kubernetes-monitoring-stack/agents/scientific-history-agent/mobile_web.html ~/GoogleDrive/
```

Затем откройте файл в облаке со смартфона.

### Способ 5: Локальный веб-сервер

Если компьютер и смартфон в одной сети:

```bash
cd /home/user/kubernetes-monitoring-stack/agents/scientific-history-agent
python3 -m http.server 8000
```

Затем на смартфоне откройте:
```
http://IP-вашего-компьютера:8000/mobile_web.html
```

Узнать IP компьютера:
```bash
# Linux/Mac
hostname -I
# или
ifconfig | grep inet
```

### Способ 6: USB кабель

**Android:**
1. Подключите смартфон по USB
2. Включите "Передача файлов"
3. Скопируйте файл в папку Downloads

**iOS:**
1. Используйте iTunes или Finder
2. Синхронизируйте файлы

### Способ 7: Мессенджеры

Отправьте файл себе через:
- Telegram (Saved Messages)
- WhatsApp (себе)
- Viber
- и т.д.

## ✨ Быстрый старт после получения файла

1. **Откройте файл на смартфоне**
   - В браузере: File → Open или из Downloads

2. **Добавьте в закладки**
   - Chrome: ⭐ → Add bookmark
   - Safari: Share → Add to Home Screen

3. **Используйте!**
   - Выберите пример запроса
   - Или введите свой
   - Тапните "🔍 Найти источники"
