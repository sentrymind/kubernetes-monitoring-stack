**На компьютере:**

## 🔧 Расширенные возможности (для продвинутых)

### Установить Termux для полного функционала Python

1. **Установите Termux:**
   - НЕ из Google Play (устаревшая версия!)
   - Скачайте из F-Droid: https://f-droid.org/packages/com.termux/

2. **В Termux выполните:**
```bash
# Обновление
pkg update && pkg upgrade

# Установка Python и Git
pkg install python git

# Клонирование репозитория
git clone https://github.com/sentrymind/kubernetes-monitoring-stack.git

# Переход в папку
cd kubernetes-monitoring-stack/agents/scientific-history-agent

# Установка зависимостей
pip install requests

# Запуск офлайн демо
python demo_offline.py
```

3. **Готово!** Теперь у вас полная версия с Python

### Что дает Termux:
- ✅ Полный функционал агента
- ✅ Экспорт в JSON/Markdown/CSV
- ✅ Настройка конфигурации
- ✅ Запуск тестов
- ✅ Реальные поиски в API (если есть интернет)

## 🆘 Решение проблем

### Ссылка не открывается
- Убедитесь, что скопировали **всю** ссылку целиком
- Попробуйте другой браузер (Firefox, Opera)

### Файл скачивается вместо открытия
- После скачивания откройте из папки "Загрузки"
- Выберите "Открыть в Chrome"

### Страница пустая или не работает
- Обновите страницу (потяните вниз)
- Очистите кэш браузера
- Попробуйте режим инкогнито

### Не добавляется на главный экран
- Используйте Chrome (не все браузеры поддерживают)
- Попробуйте: Settings → Add to Home screen

## 📞 Быстрая помощь

**Вопрос:** Где сохраняются результаты?
**Ответ:** В памяти браузера. Для постоянного сохранения используйте Termux версию.

**Вопрос:** Нужен интернет?
**Ответ:** Только для первого открытия. Потом работает офлайн.

**Вопрос:** Это безопасно?
**Ответ:** Да, файл не требует никаких разрешений и работает локально в браузере.

**Вопрос:** Сколько места занимает?
**Ответ:** Всего ~15 KB (меньше чем фото!)

**Вопрос:** Можно ли редактировать?
**Ответ:** Да, файл - это обычный HTML. Можете открыть текстовым редактором.
