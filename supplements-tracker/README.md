# 💊 Трекер приема БАДов

Комплексное приложение для отслеживания приема БАДов (Омега-3 и витамин D3-K2) с визуализацией результатов, аналитикой и генерацией отчетов.

## ✨ Возможности

### 📊 Основной функционал

- **Ежедневный учет приема БАДов**
  - Отслеживание приема Омега-3 (EPA+DHA)
  - Отслеживание приема витамина D3
  - Отслеживание приема витамина K2 (опционально)
  - Запись дозировок

- **Мониторинг самочувствия**
  - Уровень энергии (1-10)
  - Качество сна (1-10)
  - Настроение (1-10)

- **Результаты анализов**
  - Уровень витамина D (25-OH) в нг/мл
  - Омега-3 индекс в %
  - История изменений показателей

### 📈 Аналитика и визуализация

- **Графики динамики**
  - График уровня витамина D с целевой зоной (50-80 нг/мл)
  - График омега-3 индекса
  - Тренды показателей самочувствия

- **Календарь приема**
  - Тепловая карта приема Омега-3
  - Тепловая карта приема витамина D3

- **Корреляционный анализ**
  - Связь между приемом БАДов и самочувствием
  - Визуализация корреляций

- **Статистика**
  - Процент дней с приемом
  - Средние показатели самочувствия
  - Средние дозировки

### 🎯 Дополнительные функции

- **Прогноз достижения целей**
  - Расчет времени до достижения целевого уровня витамина D
  - Рекомендации по дозировке

- **Напоминания**
  - Напоминание о необходимости сдать анализы (каждые 3 месяца)

- **Учет стоимости**
  - Отслеживание покупок БАДов
  - Расчет общих расходов за период
  - Статистика по затратам

- **Импорт/Экспорт**
  - Импорт данных из CSV
  - Экспорт данных в CSV
  - Экспорт отчетов в PDF

## 🚀 Установка и запуск

### Требования

- Python 3.8+
- pip

### Установка зависимостей

```bash
cd supplements-tracker
pip install -r requirements.txt
```

### Запуск приложения

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## 💻 Использование

### 1. Добавление ежедневной записи

1. Перейдите в раздел "Добавить запись"
2. Выберите дату
3. Отметьте принятые БАДы и укажите дозировки
4. Оцените показатели самочувствия
5. Добавьте заметки (опционально)
6. Нажмите "Сохранить запись"

### 2. Добавление результатов анализов

1. Перейдите в раздел "Анализы"
2. Раскройте форму "Добавить результаты анализов"
3. Введите дату и показатели
4. Сохраните результаты

### 3. Просмотр статистики

1. Откройте раздел "Дашборд"
2. Изучите метрики и графики
3. Проверьте корреляции между приемом и самочувствием

### 4. Учет стоимости

1. Перейдите в раздел "Стоимость"
2. Добавьте информацию о покупке
3. Просматривайте статистику расходов

### 5. Генерация отчетов

1. Откройте раздел "Отчеты"
2. Просмотрите текстовый отчет
3. Сгенерируйте PDF отчет для скачивания

### 6. Импорт/Экспорт данных

**Импорт из CSV:**
1. Перейдите в раздел "Импорт/Экспорт"
2. Выберите таблицу для импорта
3. Загрузите CSV файл
4. Подтвердите импорт

**Экспорт в CSV:**
1. Выберите таблицу для экспорта
2. Нажмите "Экспортировать"
3. Скачайте сгенерированный файл

## 📊 Целевые показатели

### Витамин D (25-OH)
- **Оптимальный уровень:** 50-80 нг/мл
- **Минимальный уровень:** 30 нг/мл
- **Рекомендуемая доза:** 2000-5000 МЕ/день

### Омега-3 индекс
- **Оптимальный уровень:** >8%
- **Приемлемый уровень:** 4-8%
- **Низкий уровень:** <4%
